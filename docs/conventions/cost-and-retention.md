# 비용·보관

## MVP 비용 기대

| 항목 | 기대 |
| --- | --- |
| Vercel / Supabase / Inngest | 무료 티어 범위 목표 (트래픽·저장 주의) |
| OpenAI API | **유료**. ChatGPT Plus와 **별도** 결제 — MVP는 **개인 API 계정·카드** (사용자 확정) |
| 주 1회 · 90분 회의 (대략) | 받아쓰기 ~$0.4/회 + Luna 소액 → **월 수 USD** |

「완전 무료 MVP」는 **OpenAI를 쓰는 한 불가능**하다. 무료만 고집하면 STT·LLM 공급자를 바꾸거나 로컬 STT로 ADR을 다시 써야 한다.

---

## OpenAI 사용량 가드

- 녹음 **3시간 자동 종료**.
- 개발·스테이징에서 **전체 회의 파일 반복 호출** 금지 (팀 규칙).
- 받아쓰기 **재실행은 사용자 명시 재시도**에만 (자동 루프 없음).

---

## Supabase 무료 저장 (대략)

- Storage **~1GB** 수준. 주 1회 1~2시간 오디오면 **몇 달** 내 압박 가능.
- **자동 정리**로 용량을 맞춘다 (아래 「오디오 90일」).

---

## 오디오 자동 보관 (확정)

**회의 종료 시각 기준 90일**이 지나면 **Storage의 음성 파일만** 자동 삭제한다. (업로드가 늦어도 기준은 회의 종료 시각 하나로 통일한다.)

| 90일 후 | |
| --- | --- |
| **삭제** | 오디오 파일(Storage) |
| **유지** | 회의 목록·제목, 할 일, AI 요약, 내 메모, 받아쓰기 텍스트(DB) |

**사용자 체감**

- ⑤ 목록 · ⑥ 할 일/요약/챗봇 → **그대로** 사용 가능.
- ⑥ 오디오 탭 · 구간 **재생** → 불가. 「녹음 보관 기간(90일)이 지나 파일이 삭제되었습니다」 등 **짧은 안내** (handoff 톤).

**하지 않는 것 (MVP)**

- 90일에 **회의 행·할 일·요약을 통째로** 자동 삭제하지 않음.
- 사용자에게 매주 「정리해 주세요」 클릭을 요구하지 않음 (백그라운드 job).

**실행**

- 주기적 job(예: Inngest cron)이 대상 회의를 찾아 Storage 객체 삭제 후, 회의의 **오디오 보유**를 `expired`로 바꾼다. 처리 상태(`ready` 등)는 건드리지 않는다. [plan.md](../plans/mvp-engineering/plan.md) §5
- 처음부터 녹음이 없던 회의(`none`)와 **구분**한다.

**변경**

- 90일은 convention 기본값. 변경 시 이 문서와 [data-semantics.md](../architecture/data-semantics.md) 갱신.

## 개인정보·보관

- 1인용이지만 **팀원 목소리**가 오디오에, **팀원 발언 내용**이 받아쓰기 텍스트에 포함된다.
- **90일 정리는 오디오만** 줄인다. 받아쓰기·요약 텍스트는 사용자가 회의를 삭제하기 전까지 **기한 없이 남는다.** 텍스트까지 줄이려면 별도 정책·ADR이 필요하다.
- 챗 대화 **MVP DB 미저장** — 분실 가능성은 사용자 1인 사용에 허용.
