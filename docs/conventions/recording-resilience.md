# 녹음·업로드·복구 규칙

---

## IndexedDB (로컬 임시 저장)

**용도:** 회의 **진행 중** 음성 조각과 (선택) 메모를 **노트북·해당 Chrome** 안에 자동 저장.

| 시점 | IndexedDB |
| --- | --- |
| 녹음 중 | 조각 누적 |
| 업로드 성공 확인 후 | 해당 회의 버퍼 **삭제** |
| 업로드 전에 앱을 다시 열었을 때 | 버퍼 **유지** + 「올리지 못한 녹음이 있습니다」 안내 |
| 다른 PC | **없음** (클라우드만) |

이유: [ADR-0004](../adr/0004-indexeddb-recording-buffer.md)

**사용자 행동:** 중간 「저장」 버튼 없음. flush 주기는 구현 세부(코드).

**자동 삭제 금지:** 업로드되지 않은 버퍼는 **기한으로 지우지 않는다.** 로컬 원본이 유일본일 수 있다. 정리는 업로드 성공 또는 사용자의 명시적 포기로만 한다. (클라우드 90일 정책과 무관 — [cost-and-retention.md](./cost-and-retention.md))

---

## 업로드

- 종료 후 **클라우드 Storage로 직접** (앱 서버 경유하지 않음). [ADR-0005](../adr/0005-direct-to-object-storage-upload.md)
- 실패: **재업로드** UI. **다시 녹음하라고 요구하지 않음.**
- 로컬에 조각이 남아 있으면 복구·이어하기 가능.

## 녹음이 없는 회의 (memo-only)

- 녹음 자동 감지 **없음** (handoff).
- 오디오 없이 메모만 저장 **허용** → 오디오 보유 `none`.
- 받아쓸 음성이 없으므로 AI 파이프라인은 돌리지 않는다. 처리 상태는 요약을 시도하지 않은 채 종료한다.
- **90일 만료(`expired`)와 다르다.** 만료는 「있었는데 정리됨」이다. [plan.md](../plans/mvp-engineering/plan.md) §5

## STT 입력 제약 (OpenAI)

- 파일 **25MB** 초과 시 분할 (문장 중간 자르기 지양).
- `gpt-4o-*-transcribe` 계열의 **약 25분/파일** 제한 회피를 위해 MVP는 **gpt-transcribe + 분할**을 기본으로 한다.
