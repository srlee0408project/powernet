## Empty / Error (minimum)

| State | Behavior |
| --- | --- |
| No meetings | ⑤ empty + ① 링크 |
| No todos after AI | empty todos + summary/chat/play |
| AI fail | memo + audio 유지; `regenerate` + soft message |
| Mic denied | ② 진입 차단; 권한 안내 카드 1장 |
| Chat out of scope | 「이 회의 기록에 없어요」+ todos 링크 |

---

## Lucide (필수)

`mic`, `square`, `folder-open`, `check`, `loader-circle`, `circle`, `check-circle`, `list-todo`, `filter`, `play`, `headphones`, `message-circle`, `send`, `lock`, `arrow-left`, `pencil`, `rotate-cw`, `leaf`, `globe`, `x`, `panel-left`, `clipboard-copy`

Sizes: nav 20px · inline 16–18px · launcher 22–26px

---

## Non-goals (MVP)

- Mobile / &lt; 1024px  
- Team share, comments, @mention  
- Speaker diarization UI  
- Full transcript reader  
- Cross-meeting chat search  
- Push notifications  
- Online meeting bot / Zoom integration
