## 제품 원칙 (veto rule)

> **손이 더 많이 가면 사용을 중단한다.**

- Cold start(①)는 **녹음 CTA 중심**. 대시보드·알림·사전 설정 없음.
- **1인 개인용** — 공유·권한·팀 협업 없음.
- **전사 원문 풀뷰 UI 없음** — 접근은 **구간 재생** + **회의 1건 챗봇**만.
- **푸시/이메일 알림 없음.**
