# 도메인 스토리텔링: 나만의 회의록 에이전트

- 작성일: 2026-09-17
- 도메인 전문가: 서비스 사용자 본인 (1인 개인 사용)
- 방식: 도메인 스토리텔링 인터뷰 (AS-IS → 통증 → TO-BE)
- 기준 상황: **매주 수요일 정기 회의 / 오프라인 / 참석자 6명(팀원 5명 + 나)**

---

## 1. 등장 요소

### 행위자 (Actor)

| 행위자 | 역할 |
| --- | --- |
| 나 | 회의 참여자이자 유일한 기록자. 이 서비스의 단독 사용자 |
| 팀원 5명 | 한 명씩 돌아가며 발언. 기록 행위에는 관여하지 않음 |
| 회의록 에이전트 | (TO-BE) 회의 전체를 기록하고 요약하며, 질문에 답하는 대리인 |

### 업무 대상 (Work Object)

| 대상 | 설명 |
| --- | --- |
| 회의 | 매주 수요일, 1~2시간, 기능 개발 건과 고객 이슈를 논의 |
| 내 메모 | 내가 직접 타이핑한 기록. 내 할 일 / 다음 미팅 일정 / 중요 이슈 |
| 녹음 파일 | 회의 원본 음성. 대부분 녹음하지만 간헐적으로 누락 |
| 회의 요약 | (TO-BE) 녹음 종료 시 자동 생성. 수정 가능 |
| 할 일 항목 | (TO-BE) 마감 시점 / 요청자 / 나온 안건 / 완료 표시를 가진 항목 |
| 회의 챗봇 | (TO-BE) 해당 회의 한 건의 기록만 아는 대화 상대 |

---

## 2. AS-IS 스토리: "수요일 회의와 사라지는 기억"

### 장면 1. 회의 전

1. 나는 지난주 **내 메모**를 열어 되짚어 본다. 회의 중에 열어보는 주도 있다.
2. 나는 **녹음기**(휴대폰 또는 PC 녹음기)를 켠다.
   - 주제가 짧거나 중요해 보이지 않으면 켜지 않는다.
   - 켜는 것을 깜빡 잊는 경우가 있다.

### 장면 2. 회의 중 (1~2시간)

3. 팀원 5명이 **한 명씩 돌아가며** 기능 개발 건과 고객 이슈를 이야기한다.
4. 발언자가 **나를 언급하면**, 나는 **내 메모**에 기록한다.
   - 내가 해야 할 일 / 다음 미팅 일정 / 중요한 이슈
5. 적다가 방향을 잃거나 내용이 부족하다고 느끼면, 나는 **발언이 끝난 뒤 발언자에게 되묻는다**.
6. 그럼에도 일부 내용은 메모에 남지 않는다.
   - 딴생각 / 다른 화면을 보는 중 / 맥락 파악 실패 / 발화가 너무 빠름 / 타이핑이 대화 속도를 못 따라감

### 장면 3. 회의 후

7. 회의가 끝나면 나는 메모를 **정리하지 않고, 누구에게도 공유하지 않는다**.
8. 며칠 뒤 해당 업무를 착수할 때, 나는 **내 메모를 다시 열어** 할 일을 확인한다.
9. 메모만으로 의미가 복원되지 않으면, 나는 **녹음 파일을 찾는다**.
10. 파일 정리가 되어 있지 않아 **시간순으로 추측**하며 후보 파일을 재생한다.
11. 원하는 대목의 위치를 몰라 **배속 재생하거나 여러 번 스킵**하며 예상 지점을 뒤진다.

## 3. 통증 지점

| # | 통증 | 지금 벌어지는 일 |
| --- | --- | --- |
| P1 | 기록의 구멍 | 나를 언급한 대목만 남고, 나머지 논의는 사라진다 |
| P2 | 기록과 참여의 충돌 | 타이핑 속도가 대화 속도를 따라가지 못한다 |
| P3 | 켜는 것을 잊음 | 녹음 여부가 내 기억력과 그때의 판단에 의존한다 |
| P4 | 파일 식별 불가 | 어느 파일이 그 회의인지 시간순 추측으로 찾는다 |
| P5 | 지점 탐색 불가 | 통 덩어리 오디오에 목차와 색인이 없다 |
| P6 | 의미 복원 실패 | 시간이 지나면 내 메모의 단어가 무슨 뜻이었는지 알 수 없다 |

---

## 4. TO-BE 스토리: "노트북 하나로 끝나는 회의"

### 장면 1. 회의 시작

1. 나는 **노트북과 휴대폰**을 들고 밀폐된 회의실에 들어간다. 작업의 중심은 노트북이다.
2. 나는 앱을 열고, 첫 화면에 크게 보이는 **녹음 시작 버튼**을 누른다.
   - 첫 화면에는 그 외의 정보가 필요하지 않다.
   - 사전 설정이나 참석자 등록 같은 추가 절차는 없어야 한다.

### 장면 2. 회의 중

3. 에이전트는 회의 **전체 음성을 자동으로 기록**한다.
4. 나는 그와 별개로 **여전히 직접 메모를 한다**. AS-IS와 동일한 항목을 그대로 적는다.

### 장면 3. 녹음 종료 직후

5. 내가 녹음을 끄면, 에이전트는 **곧바로 화면에 요약을 보여준다**.
6. 나는 요약에서 **내 할 일을 가장 먼저 확인**한다.
7. 나는 요약 내용을 **직접 수정하고 보완한다**.
8. 할 일 항목에는 다음이 담긴다.
   - 언제까지 해야 하는지
   - 누가 요청했는지 (대화 맥락에서 자동 추정, 틀리면 내가 직접 작성)
   - 어떤 안건에서 나온 이야기인지
   - 완료 표시
9. 회의에는 내용을 알아볼 수 있는 **제목/주제**가 붙는다.

### 장면 4. 며칠 뒤 업무 착수

10. 나는 회의 목록에서 **제목이나 주제를 눈으로 훑어** 그 회의를 찾아 들어간다.
11. 나는 할 일 항목을 보고 업무를 시작한다.
12. 의미가 불분명하면 나는 두 가지 중 하나를 한다.
    - **그 대목의 음성을 듣는다** (해당 지점부터 재생)
    - **회의 챗봇에게 묻는다** (예: "내가 해야 할 일 뭐였지", "고객 이슈가 뭔지 알려줘")
13. 챗봇은 **그 회의 한 건의 기록만** 알고 있으면 충분하다.
14. 나는 긴 원문 전체를 눈으로 읽지 않는다. 챗봇이 대신 읽어주는 역할을 한다.
15. 할 일을 마치면 나는 **완료 표시**를 한다.
16. 이 모든 기록은 **나만 본다.** 팀에 공유하지 않는다.

---

## 5. 통증 → TO-BE 대응

| 통증 | TO-BE에서의 해소 |
| --- | --- |
| P1 기록의 구멍 | 회의 전체 음성이 자동 기록되어, 내가 안 적은 부분도 남는다 |
| P2 기록과 참여의 충돌 | 타이핑이 유일한 기록 수단이 아니게 된다 |
| P3 켜는 것을 잊음 | 첫 화면의 큰 녹음 버튼으로 진입 마찰을 최소화 (완전한 해소는 아님) |
| P4 파일 식별 불가 | 회의마다 알아볼 수 있는 제목이 붙고 목록에서 훑어 찾는다 |
| P5 지점 탐색 불가 | 해당 대목부터 재생, 그리고 챗봇 질의로 대체 |
| P6 의미 복원 실패 | 요약 + 챗봇이 맥락을 되살린다 |

## 6. 확정된 범위 결정

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 사용자 수 | **1인 개인 용도** | 공유하지 않음. 계정/권한 체계 불필요 |
| 공유 기능 | **없음** | AS-IS에서도 공유 화살표가 존재하지 않았음 |
| 챗봇 범위 | **회의 1건 단위** | 여러 회의를 아우르는 질문은 하지 않음 |
| 발언자 구분 | **불필요** | 목소리 주인 식별은 중요하지 않음 |
| 요청자 정보 | **맥락 기반 자동 추정 + 수동 수정** | 무거운 음성 분리 없이 해결 |
| 회의 형태 | **오프라인 우선** | 온라인은 이후 단계 |
| 녹음 환경 | **노트북 마이크 단독** | 밀폐된 회의실, 노이즈 문제 없음 |
| 첫 화면 | **녹음 시작 버튼 중심** | 지난주 요약이나 미완료 목록은 필요 없음 |
| 원문 열람 | **직접 읽지 않음** | 챗봇과 부분 재생이 원문 접근 창구 |

### 절대 지켜야 할 제약

> **손이 더 많이 가면 사용을 중단한다.**
> 사용 중단의 유일한 이유로 지목된 항목. 모든 기능은 "추가 수고 없음"을 최우선으로 설계해야 한다.

## 7. 아직 열려 있는 질문

1. **요약의 구성**: 할 일 외에 "회의 내용 요약"은 어떤 형태여야 하는가? (안건별 정리 / 시간순 흐름 / 결정 사항 목록)
2. **"곧바로"의 기준**: 녹음 종료 후 요약까지 몇 초 또는 몇 분까지 기다릴 수 있는가?
3. **회의 제목**: 자동 생성인가, 내가 붙이는가? 자동 생성이 어색하면 수정할 것인가?
4. **내 메모와 AI 요약의 배치**: 나란히 두 칸인가, 하나로 합쳐지는가? 둘이 충돌할 때 무엇을 신뢰하는가?
5. **중복 기록의 지속성**: "그럼에도 똑같이 적을 것 같다"고 했으나, 실제 사용 후 습관이 줄어드는지 관찰 필요
6. **미완료 할 일**: 완료 표시는 원하지만 미완료 알림은 원하지 않았다. 그렇다면 미완료 항목은 어디에서 다시 마주치는가?
7. **다음 미팅 일정**: 기록으로만 남는가, 알림이 필요한가? (미확인)
8. **녹음 누락 대비**: 회의가 시작됐는데 녹음을 켜지 않은 상황을 서비스가 알아챌 수 있는가?
9. **온라인 회의**: 이후 단계에서 어떻게 확장하는가?
